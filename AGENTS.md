# Directives du projet (Antigravity)

## Synchronisation GitHub automatique
- **Règle absolue :** À la fin de chaque tâche ou ensemble de modifications apportées aux fichiers du projet, l'agent **doit impérativement** sauvegarder et publier automatiquement les modifications sur GitHub.
- **Étapes à exécuter avant de terminer la réponse :**
  1. `git add -A`
  2. `git commit -m "<message clair et concis décrivant les modifications en français>"`
  3. `git push origin main`
- Vérifier que la commande `git push` réussit bien.
